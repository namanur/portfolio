# Design Principles

This repository is the durable source of truth for the portfolio.

## Attention
Every section establishes a primary, secondary, supporting, and background level. Visual emphasis is allocated deliberately.

## Anti-vibecode
Avoid fashionable defaults unless the content or interaction genuinely calls for them. Gradients, glass, generic card grids, decorative icons, fake testimonials, fake metrics, gratuitous hover effects, and other familiar AI-web patterns are warnings, not absolute bans.

## Typography
Type is structural. Font choice, scale, measure, line-height and responsive behavior are treated as a system.

## Imagery
Images and screenshots must communicate something. Decorative imagery should never compete with the message.

## Motion
Motion exists to explain continuity, emphasis or state. Respect `prefers-reduced-motion`.

## Architecture over memory
If a decision can be encoded in code, tokens, components, data or deterministic checks, encode it there. If it cannot, document it briefly.

## Honesty
Independent/concept work is labeled as such. No fabricated testimonials, client claims, metrics, credentials or product outcomes.
