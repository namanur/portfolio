# Naman Portfolio

A static portfolio and three independently browsable showcase builds.

## Structure

- `index.html` — portfolio
- `showcases/cafe-aava/` — Indian-context independent landing-page build
- `showcases/atelier-north/` — global-feeling independent brand build
- `showcases/frontend-lab/` — dense dashboard/interface study
- `assets/site.css` — shared design system
- `assets/site.js` — progressive reveal + smooth navigation
- `docs/design-principles.md` — durable design/engineering principles

## Before sending to a client

Contact details are live (email + WhatsApp). The two brand showcases are explicitly presented as independent fictional builds. Do not represent them as client work.

## Local preview

Any static server works. For example:

`python3 -m http.server 8000`

Then open `http://localhost:8000/`.

## Design intent

The site is intentionally not a default AI-web composition. It avoids relying on a giant card grid, purple/black gradients, glass panels, decorative sparkle icons, fake testimonials, fake metrics, or motion without a job.

The visual language is editorial: warm paper, ink, a restrained accent system, oversized typography, asymmetry, strong rules, and motion used primarily for continuity.
