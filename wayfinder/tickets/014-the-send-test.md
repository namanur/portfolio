# The send test — would Naman actually send this for ₹20–25k?

Labels: wayfinder:grilling
Status: open
Assignee: (unclaimed)
Blocked-by: 022

## Question

Walk the live portfolio as a skeptical client who could pay ₹20–25k, then as Naman deciding whether to send it. Does the site alone communicate taste, design judgment, and capability? List every gap that would cause hesitation — visual, copy, motion, responsive, credibility — decide which are real blockers versus acceptable, and either fix them via follow-up tickets or declare the destination reached. Done means the answer to "would I send this?" is yes, without explaining anything away.
