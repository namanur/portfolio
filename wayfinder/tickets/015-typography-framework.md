## Question

What typography framework should govern this portfolio and its showcases? Investigate against authoritative sources (NN/g, Material typography structure, WCAG 2.2, MDN): font *selection* criteria (brand personality, readability, character, width, weight range, display-vs-body contrast, licensing, performance, responsive behavior — explicitly rejecting fashionable AI-web defaults like Inter/Geist/Space Grotesk unless a real reason exists); the *minimum* set of type styles needed for hierarchy without visual noise (Material warns excess sizes damage layout); readable **measure** (WCAG's 80-character benchmark as a constraint, not a universal constant); line-height/tracking/paragraph-spacing by role (display vs heading vs body, unitless line-height per MDN); and **responsive typography as a system** (heading scale, measure, line breaks, density across large desktop / laptop / tablet / mobile). Deliver: a concise typography framework with concrete recommendations, each recommendation tagged Evidence / Convention / Taste / Project constraint.
