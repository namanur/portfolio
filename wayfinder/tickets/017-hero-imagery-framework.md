## Question

What makes a hero and an image placement earn their place? **Hero**: build an evaluation framework (Message, Audience, Differentiation, Proof, Visual anchor, Action, Hierarchy, Continuation) and survey hero composition types — type-dominant, image-dominant, product-preview, editorial, split, asymmetric, full-bleed, immersive-narrative — to determine which fits this portfolio's actual proposition: a self-taught designer whose portfolio itself is the proof. Explicitly catalog the AI-generated-hero pile-up to avoid: giant heading + gradient blob + floating cards + two buttons + decorative orb + sparkle icon + fake metric. **Imagery**: NN/g's meaningful-imagery research — images that communicate or reinforce the message vs decorative images users ignore ("What does this image communicate that text alone cannot?"). Cover showcase screenshot treatment: cropping, aspect ratio, device framing, full-page vs focused, detail crops, desktop/mobile pairing, before/after, image sequencing, scroll-based reveals, and responsive image art direction (web.dev `<picture>`/performance guidance). Deliver concrete patterns and anti-patterns, tagged Evidence / Convention / Taste / Project constraint.
